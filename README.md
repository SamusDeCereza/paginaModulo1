En este repositorio se entuentra el proyecto final correspondiente al 
modulo 1 "Introduccion a la programacion", del curso FrontEnd en la 
plataforma Campus propiedad de DevF.

Dicho proyecto esta realizado con CSS, JavaScript y HTML, que en conjunto
crean una pagina dinamica, como parte de mi aprendizaje y reforzamiento en 
conocimientos de desarrollo web. 

--

## Clonando el repositorio

Mediante el powershell en windows, o la terminal correspondiente de tu sistema 
operativo, podemos clonar el repositorio de la siguiente manera:

``` bash
git clone https://github.com/dannielgloria/proyecto-final-3-WEB-A.git
```


##  Ejecutar el proyecto con Live Server

La pagina se puede visualizar abriendo el archivo index.html en un navegador web, pero 
para mayor comodidad, podemos utilizar la extension Live Server que va a reflejar los 
cambios que hagamos sin necesidad de refrescar la pagina.

### Instalar la extensión Live Server

En Visual Studio Code:

-   Ve a la sección **Extensions** (`Ctrl + Shift + X`)
-   Busca **Live Server**
-   Instala la extensión desarrollada por **Ritwick Dey**

---

### Iniciar el servidor

1.  Abre el archivo `index.html`
2.  Haz clic derecho
3.  Selecciona **"Open with Live Server"**

Tu navegador se abrirá automáticamente mostrando el proyecto.
